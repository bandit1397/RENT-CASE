# RENT-CASE

임대차 보증금·경매 배당 관련 문서 모음입니다. 각 문서는 출력용 PDF와 수정용 워드 파일(.docx)로 함께 올려 두었습니다. 개인 인적사항(이름, 연락처, 주소, 사건번호, 채권자명)은 ○로 가렸습니다.

| 파일 | 내용 |
|---|---|
| 임대인_해지통지_대응_및_발송문안_최종본.pdf | 임대인 해지 통지에 대한 법적 검토, 발송 문자 최종본, 반응별 대응 |
| 배당요구_소명자료_제출서.pdf | 경매법원 제출용 임차인 배당요구 관련 소명자료 제출서 |
| 거주사실_확인서_이웃세입자용.pdf | 이웃 세입자에게 받을 거주사실 확인서 양식 |
| 실거주_증빙자료_안내.pdf | 첨부 서류 발급처와 실거주를 증명할 수 있는 자료 안내 |
| 실거주사실_확인_문구.pdf | 이웃 주민이 작성하는 실거주사실 확인 문구 |

## 수정해서 쓰는 방법

- `.docx` 파일을 한글(한컴오피스)이나 MS 워드에서 열어 빈칸(______)을 채우고 출력하면 됩니다.
- 한글 파일로 보관하려면 한글에서 [파일] → [다른 이름으로 저장] → "한글 문서(*.hwp)"를 고르세요.
- 한글·워드가 없으면 구글 문서나 한컴독스 웹에서 열어 수정할 수 있습니다.

※ 참고용 자료이며 변호사의 법률 자문을 대신하지 않습니다.
